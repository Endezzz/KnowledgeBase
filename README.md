# `KnowledgeBase`

## *Описание:*
> KnowledgeBase - это консольное приложение, которое позволяет удобно ввести список различных исочников в электронном формате. 

## *Основные функции:*
 * Считывание источников из файла
 * Добавление */* удаление */* редактирование источника
 * Сортировка по статусу и важности источника
 * Вазможность открыть источник через консоль

## *Основные технологии:*
|      Компонент       | Технология |
|----------------------|:----------:|
|Язык программирования |     C++    |
|Принцип               |    CRUD    |
|Графическая библиотека|  Win32 API |
|Подход к разработке   |     OOP    |

## *Запуск:*

1. Клонирование репозитория
```git clone https://github.com/Endezzz/KnowledgeBase.git```

2. Компиляция в папке **src**
``` cd .\src\```

```g++ main.cpp functions.cpp -o main```

3. Демонстрация работы
```./main```
